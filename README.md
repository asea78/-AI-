## 收录原则

- 优先保留原项目链接和作者信息。
- 根据项目用途与许可证，决定只记录链接、Fork，或选择性复制文件。
- 收录前检查项目说明、依赖、许可证和基本安全风险。
- 不将他人的项目标记为原创；不收录密钥、密码或个人隐私。

## 如何添加工具

把 GitHub 仓库链接发给我，并说明希望收录即可。我会先分析项目，再提出合适的收录方式；涉及复制代码或其他实质性修改时，会先向你说明。
